### Yenilikler

**Altı yapay zekâ sağlayıcısı**
* **Claude** (resmi Anthropic .NET SDK), **OpenAI**, **DeepSeek** ve OpenAI uyumlu her sunucu (LM Studio, vLLM, llama.cpp, OpenRouter, Groq, Mistral…). **Gemini** ve **Ollama** desteği sürüyor; Ollama artık `/api/chat` kullanıyor.
* Şema tek ve sabit bir sistem prompt'unda durur. Claude bunu açıkça önbelleğe alır, diğer sağlayıcılar ortak başlığı kendiliğinden yeniden kullanır. Token kullanımı ve önbellek isabeti canlı gösterilir ve raporla saklanır.
* Bulut çalıştırmaları birden çok konuyu paralel yanıtlar (1–8 arası, önce bir önbellek ısıtma isteği gider). Geçici hatalarda bir kez daha denenir, kopan bağlantılar yeniden kurulur, akıl yürüten modellerin `<think>` blokları temizlenir.
* Her sağlayıcı kendi modelini, adresini, bağlam boyutunu ve anahtarını saklar. Anahtarlar işletim sisteminin anahtar zincirinde durur. Sağlayıcı kartları, önerilen modeller ve canlı model listesi eklendi.

**Analiz konuları**
* Katalog baştan denetlendi: çıkarımın sağlamadığı veriyi isteyen ya da konu dışı kalan başlıklar yeniden yazıldı, motora özgü prompt'lar motordan bağımsız hâle getirildi.
* 8 kategoride **59 konu**. Yeni kategoriler: **Veri kalitesi**, **Uyumluluk (GDPR / KVKK / PCI DSS)**, **Operasyon** ve **Geliştirici**.
* **7 hazır set** eklendi. Örnek satır ya da SQL kaynak kodu gerektiren bir konu seçildiğinde, bu veri çıkarılmamışsa uyarı gösterilir.
* Cevaplar motorun SQL lehçesinde yazılır, nesnelere ters tırnakla atıf yapar ve çevrimdışı bulguların üzerine kurulur.

**Veritabanları**
* **Oracle 12.2+**: şemalar veritabanı olarak listelenir; EZConnect ya da TNS tanımı, LONG sütunlar ve PL/SQL paket gövdeleri desteklenir.
* **SQLite**: dosya salt okunur açılır. `rowid` anahtarları, tablo SQL'inden okunan `CHECK` kısıtları ve satır sayıları desteklenir.
* Oracle Free 23ai, SQLite 3, PostgreSQL 16 ve MariaDB 10.11 üzerinde uçtan uca doğrulandı.

**Analiz ↔ ER diyagramı**
* **Sağlık katmanı**: her tablo en ciddi bulgusunun renginde görünür.
* **Etki alanı**: `ON DELETE CASCADE` zincirleriyle birlikte, bir tablodaki değişikliğin nereleri etkilediğini gösterir.
* **Komşu odaklama**, `JOIN` sorgusunu yazan **birleştirme yolu bulucu** ve tablo başına bulgular ile o tabloyu anan rapor bölümleri.
* Bulgulardan, sıcak noktalardan, rapordan ve sohbetten **“Diyagramda göster”**. Rapordaki tablo adları diyagramı açar, kod bloklarında kopyalama düğmesi vardır.

**Yeni özellikler**
* **AI'a Sor:** şema hakkında, önbellekli bağlamla sohbet. Cevaplarda tablo adları bağlantılıdır ve SQL kopyalanabilir. Bulgularda ve diyagram tablolarında *AI'a Sor* düğmesi vardır.
* **Anlık görüntüler:** her çıkarım (yalnızca yapı) sürümlenir ve son sürümden bu yana neyin değiştiği gösterilir. İki sürüm karşılaştırılabilir (kırıcı değişiklikler işaretlenir) ve yapay zekâya inceletilebilir. Sağlık puanı grafikle izlenir.
* **Düzeltme betiği:** indeksi olmayan yabancı anahtarlar için motorunuzun lehçesinde SQL; gereksiz indeksler ve anahtarsız tablolar için yorum satırında öneriler. Her ifade PostgreSQL, MariaDB, Oracle ve SQLite üzerinde çalıştırılarak doğrulandı.

### What's new

**Six AI providers**
* **Claude** (official Anthropic .NET SDK), **OpenAI**, **DeepSeek** and any OpenAI-compatible server (LM Studio, vLLM, llama.cpp, OpenRouter, Groq, Mistral…). **Gemini** and **Ollama** are still supported; Ollama now uses `/api/chat`.
* The schema lives in one stable system prompt. Claude caches it explicitly and the other providers reuse the prefix on their own. Token usage and cache hits are shown live and stored with every report.
* Cloud runs answer several topics in parallel (1–8, after one cache warm-up request). Transient errors get one more attempt, dropped connections are retried, and the `<think>` blocks of reasoning models are removed.
* Every provider keeps its own model, address, context size and key. Keys are stored in the OS keychain. New provider tiles, suggested models and a live model list.

**Analysis topics**
* The whole catalogue was audited: topics that asked for data the extraction does not have, or were off-topic, were rewritten, and engine-specific prompts were made engine-neutral.
* **59 topics** in 8 categories. New categories: **Data quality**, **Compliance (GDPR / KVKK / PCI DSS)**, **Operations** and **Developer**.
* **7 presets** were added. When a topic needs sample rows or SQL source code that was not extracted, the app warns you.
* Answers are written in the engine's SQL dialect, refer to objects in backticks and build on the offline findings.

**Databases**
* **Oracle 12.2+**: schemas are listed as databases; EZConnect or TNS descriptors, LONG columns and PL/SQL package bodies are supported.
* **SQLite**: the file is opened read-only. Supports `rowid` keys, `CHECK` constraints read from the table SQL, and row counts.
* Verified end to end against Oracle Free 23ai, SQLite 3, PostgreSQL 16 and MariaDB 10.11.

**Analysis ↔ ER diagram**
* **Health lens**: every table takes the colour of its worst finding.
* **Impact view**: shows what a change to a table affects, including `ON DELETE CASCADE` chains.
* **Neighbourhood focus**, a **join path finder** that writes the `JOIN` query, and per-table findings with the report sections that mention the table.
* **“Show in diagram”** from findings, hot spots, reports and the chat. Table names in reports open the diagram, and code blocks have copy buttons.

**New features**
* **Ask AI:** a chat about your schema with cached context. Table names in answers are linked and SQL can be copied. Findings and diagram tables have an *Ask AI* button.
* **Snapshots:** every extraction is versioned (structure only) and the app shows what changed since the last one. Any two versions can be compared (breaking changes are flagged) and reviewed by the AI. A chart tracks the health score.
* **Fix script:** SQL in your engine's dialect for foreign keys without an index, plus commented suggestions for redundant indexes and tables without a key. Every statement was run on PostgreSQL, MariaDB, Oracle and SQLite to verify it.

**Fixes**
* **macOS:** the app no longer crashes at launch. The PDF engine (QuestPDF) does not run under Mac Catalyst, so PDF export is turned off on macOS for now; export the report as HTML and print it to PDF from your browser.
* The version shown in Settings is now 2.1.0.
* Counts on the ER diagram use the right singular / plural (*1 view*).
* The Claude API key link points to the new Claude Console (platform.claude.com).
* The licence file moved to the repository root, so GitHub now recognises the MIT licence.

**Tests and docs:** 98 core tests (up from 38). The README was rewritten in English and Turkish. The Windows and macOS packages are now built automatically on GitHub Actions and are only published once each app has started successfully.
