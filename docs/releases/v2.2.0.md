## 🇹🇷 Türkçe

### İndir

| Dosya | Sistem |
|---|---|
| `AIDatabaseAnalyzer-2.2.0-windows-x64.zip` | Windows 10 (1809 ve üstü) / 11, x64. Kurulum ve .NET gerekmez. |

Uygulama ücretli bir geliştirici sertifikasıyla imzalanmadığı için ilk açılışta işletim sistemi uyarı verir:

* **Windows:** Zip'i bir klasöre çıkarın ve `AIDatabaseAnalyzer.exe`'yi çalıştırın. *“Windows bilgisayarınızı korudu”* uyarısı çıkarsa **Ek bilgi → Yine de çalıştır** deyin.
* **macOS:** Zip'i açın, *AI Database Analyzer* uygulamasını **Uygulamalar** klasörüne taşıyın ve açın. Engellenirse **Sistem Ayarları → Gizlilik ve Güvenlik → Yine de Aç** deyin ya da Terminal'de şunu çalıştırın:
  `xattr -dr com.apple.quarantine "/Applications/AI Database Analyzer.app"`

Dosyaların SHA-256 özetleri `SHA256SUMS.txt` içindedir.

### Yenilikler

* **Demo veritabanı:** Bağlan sayfasındaki **Open the demo database** düğmesi, 12 tablolu örnek bir mağaza veritabanını (müşteriler, siparişler, ödemeler, kargolar, yorumlar…) oluşturup salt okunur açar. Tasarımında gerçek hayatta sık görülen hatalar var: düz metin parolalar, `REAL` tutulan para, eksik bir yabancı anahtar, indeksi olmayan yabancı anahtarlar, yinelenen bir indeks, anahtarsız tablolar. Böylece Insights, ER diyagramı, anlık görüntüler ve yapay zekâ analizi hiçbir sunucu kurmadan denenebilir. Tüm veriler uydurmadır.

## 🇺🇸 English

### Download

| File | System |
|---|---|
| `AIDatabaseAnalyzer-2.2.0-windows-x64.zip` | Windows 10 (1809 or later) / 11, x64. No installer, no .NET needed. |
| `AIDatabaseAnalyzer-2.2.0-macos.zip` | macOS 12 or later. Apple silicon and Intel. |

The app is not signed with a paid developer certificate, so the system warns you the first time you open it:

* **Windows:** extract the zip and run `AIDatabaseAnalyzer.exe`. If *“Windows protected your PC”* appears, choose **More info → Run anyway**.
* **macOS:** unzip, move *AI Database Analyzer* to **Applications** and open it. If it is blocked, choose **System Settings → Privacy & Security → Open Anyway**, or run:
  `xattr -dr com.apple.quarantine "/Applications/AI Database Analyzer.app"`

SHA-256 checksums are in `SHA256SUMS.txt`.

### What's new

* **Demo database:** **Open the demo database** on the Connect page creates a 12-table sample shop (customers, orders, payments, shipments, reviews…) and opens it read-only. Its design has flaws you meet in real projects: plain-text passwords, money stored as `REAL`, a missing foreign key, unindexed foreign keys, a duplicate index and tables without a key. Try the insights, the ER diagram, snapshots and the AI analysis without setting up any server. All data is fictitious.

### Fixes

* A malformed link in a report or chat page no longer crashes the app.
* Removed the unused Android, iOS and Tizen platform files (the app targets Windows and macOS only).
* The *Ask AI* and *Snapshots* images in the README were refreshed with the demo database.

**Tests:** 101 core tests (up from 98). They check that the demo database builds, reads without warnings and produces the expected findings.
