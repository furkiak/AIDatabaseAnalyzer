### Yenilikler

**Mimari**
* 600 satırlık `MainViewModel`; Bağlan, Kapsam, Insights, Analiz, Raporlar, Diyagram ve Ayarlar olmak üzere ayrı view model'lere bölündü. Bu view model'ler ortak bir `WorkspaceSession` paylaşıyor.
* Servisler bir kez kaydedilip arayüzler üzerinden kullanılıyor. Prompt'lar bir konu kataloğuna (4 kategoride 44 konu), yapay zekâ akışı ise `AnalysisRunner`'a taşındı.
* Her ekranda derlenmiş binding'ler (`x:DataType`) kullanılıyor ve şablondaki sekme çubuğunun yerine kenar çubuğu geldi.
* Platformdan bağımsız çekirdek için xUnit projesi (38 test) ve CI eklendi.

**Hata düzeltmeleri**
* Koda gömülü varsayılan kimlik bilgileri kaldırıldı. Bağlantı dizeleri sağlayıcıların builder'larıyla kuruluyor; parola üzerinden enjeksiyon artık mümkün değil.
* Gemini API anahtarı URL'den başlığa taşındı.
* Veritabanı hataları giderildi:
  * MySQL `LONGTEXT` `Int32` taşması ve `SHOW TABLES` sonucunda view'ların gelmesi.
  * PostgreSQL yabancı anahtar çapraz çarpımı ve hep yanlış dönen *unique* bayrağı.
  * Veritabanı listelerinde sistem şemalarının görünmesi ve varsayılan dışındaki şemaların atlanması.
  * Örnek sorgularda tırnaksız tanımlayıcılar ve büyük tablolarda tüm tabloyu sıralayan örnekleme.
* Türkçe yerel ayarda `ToLower()` arama hatası, sanallaştırılmamış tablo listesi ve emoji ya da eksik `Arial` yüzünden çöken PDF düzeltildi.
* ER diyagramı ilişkileri hiç çizmiyordu; düzeltildi.

**Özellikler**
* 29 kurallı çevrimdışı **sağlık puanı** ve bulgular.
* Bağımlılıksız, etkileşimli **ER diyagramı**: ilişkiler, arama, ayrıntı paneli, SVG ve tek dosya HTML dışa aktarımı.

* Raporlar:
  * Rapor geçmişi ve uygulama içi görüntüleyici.
  * PDF, Markdown ve HTML dışa aktarımı.
  * Türkçe ve İngilizce rapor dili.
* Bağlantılar: güvenli parola saklamalı kayıtlı bağlantılar ve Windows kimlik doğrulaması.
* **Liquid Glass** tasarım sistemi (açık / koyu / sistem teması), yeni uygulama simgesi ve açılış ekranı.

### What's new

**Architecture**
* The 600-line `MainViewModel` was split into separate view models for Connect, Scope, Insights, Analysis, Reports, Diagram and Settings. They share a `WorkspaceSession`.
* Services are registered once and used through interfaces. Prompts moved to a topic catalogue (44 topics in 4 categories) and the AI orchestration moved to `AnalysisRunner`.
* Every screen uses compiled bindings (`x:DataType`), and a sidebar replaced the template's tab bar.
* An xUnit project (38 tests) for the platform-independent core, plus CI.

**Bug fixes**
* Hard-coded default credentials were removed. Connection strings are built with the providers' builders, so passwords can no longer inject options.
* The Gemini API key moved from the URL to a header.
* Database fixes:
  * MySQL `LONGTEXT` `Int32` overflow, and `SHOW TABLES` returning views.
  * The PostgreSQL foreign-key cross product, and the unique flag that was always false.
  * System schemas showing up in database lists, and non-default schemas being skipped.
  * Unquoted identifiers in sample queries, and sampling that sorted the whole table on large tables.
* Fixed the Turkish-locale `ToLower()` search bug, the un-virtualised table list, and PDF crashes caused by emoji or a missing `Arial` font.
* The ER diagram never drew relationships; it does now.

**Features**
* An offline **health score** with 29 rules, and findings.
* A dependency-free, interactive **ER diagram**: relationships, search, a details panel, and SVG / standalone HTML export.
* A **privacy shield** for sample rows, and a confirmation before data goes to a cloud model.
* Network and error handling: retry with back-off, cancellation, and re-running failed topics.
* Prompts and models: model lists come from the provider, and schema-first prompts with compact JSON save tokens.
* Reports:
  * Report history and an in-app viewer.
  * PDF, Markdown and HTML export.
  * Reports in English or Turkish.
* Connections: saved connections with secure password storage, and Windows authentication.
* A **Liquid Glass** design system (light / dark / system), a new app icon and a new splash screen.
